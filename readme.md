🚀 Assignment 23 - Optional Task
📌 Project Overview

This project is developed as the Optional Task for Assignment 23. It demonstrates Machine Learning techniques on two real-world datasets.

The project includes:

🚲 Used Bike Price Prediction using Linear Regression
👨‍💼 Employee Attrition Prediction using:
Logistic Regression
K-Nearest Neighbors (KNN)
Naive Bayes
🌐 Streamlit Web Application for predictions

Joblib
